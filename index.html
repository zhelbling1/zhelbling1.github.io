rclone

FTDATACOLLECT1 Drive uploader — a private, single-user tool

What this app does

This app is a personal configuration of rclone, an open-source file copying tool. It runs on one field data-collection computer (FTDATACOLLECT1) and, once a day, copies newly recorded monitoring data files from that computer into a folder in the owner's own Google Drive, so the owner can access the data remotely.

How it uses Google data

  • It uses only the Google Drive permission drive.file, which lets it see and manage only the files it uploads itself.
  • It cannot read, change, or delete any other files in the Google Drive.
  • It is used only by the owner of this project, with the owner's own Google account. It is not offered to the public.
